PEP ENTERPRISE V4.8.0-C — PORTABLE MAC + WINDOWS
=================================================

Esta edición NO modifica el ERP V4.8.0-C estable.
Solo añade lanzadores para iniciar el servidor local automáticamente.

macOS
-----
1. Mantenga toda esta carpeta junta.
2. Doble clic en "Iniciar ERP.command".
3. El navegador abrirá automáticamente el Login de PEP Enterprise.
4. Para detener el servidor local, doble clic en "Detener ERP.command".

Si macOS bloquea el archivo .command la primera vez:
- Finder > clic derecho sobre "Iniciar ERP.command" > Abrir > Abrir.
- Si fuera necesario, abra Terminal en esta carpeta y ejecute una sola vez:
  chmod +x "Iniciar ERP.command" "Detener ERP.command"

Windows
-------
1. Mantenga toda esta carpeta junta.
2. Doble clic en "Iniciar ERP.bat".
3. El navegador abrirá automáticamente el Login de PEP Enterprise.
4. Para detener el servidor local, doble clic en "Detener ERP.bat".

REQUISITO LOCAL
---------------
Los lanzadores usan Python 3 como servidor HTTP local.
- macOS: normalmente se ejecuta como python3.
- Windows: busca py -3, python o python3.

El lanzador intenta usar localhost:8080. Si ese puerto está ocupado, usa automáticamente
8081, 8082... hasta 8090 y abre la dirección correcta.

NETLIFY
-------
Esta misma aplicación puede publicarse en Netlify usando el paquete NETLIFY READY separado.
Para usuarios finales remotos, Netlify es la opción recomendada porque no requiere Python ni
un servidor local en cada computadora.

IMPORTANTE
----------
No abra index.html directamente con doble clic (file://). Firebase Authentication y los módulos
JavaScript deben ejecutarse desde http://localhost o desde HTTPS/Netlify.
